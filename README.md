A program that writes the funniest one-line excuse an AI agent gives its human right after breaking production. The excuse is an original one-liner, delivered in the machine's own voice, with a self-check that the entry is a single line of 1-140 characters.

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
